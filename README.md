# Hospital Management Dashboard

## Project Overview
This project uses Microsoft Power BI to analyze hospital data related to patients, doctors, treatment costs, diagnoses, and admissions.

## Key Performance Indicators (KPIs)
- Total Patients: 250
- Total Treatment Cost: 1.98K
- Average Length of Stay: 5.39
- Visit Dates: 142
- Total Doctors: 10

## Dashboard Features
- Department by Doctor
- Age by Treatment Cost
- Treatment Cost by Doctor
- Doctor by Diagnosis
- Patient Visits by Date
- Doctor by Length of Stay
- Patient Admission Type
- Insurance by Admission Type

## Tools Used
- Microsoft Power BI
- Data Analysis
- Data Visualization

## Skills Demonstrated
- KPI Cards
- Charts and Graphs
- Data Analysis
- Dashboard Design

## Conclusion
This dashboard provides an overview of hospital operations, patient visits, doctor-related information, treatment costs, and admission patterns.
